# Dual-Zone Tropical Agrivoltaic AI Irrigation Simulation

Stochastic digital twin of a 70-day dual-zone tropical agrivoltaic experiment for 24-hour soil-moisture forecasting and irrigation-policy evaluation.

## Environment Setup
Requires Python 3.12.x.
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
